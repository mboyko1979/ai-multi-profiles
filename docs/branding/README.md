# AI Multi Profiles artwork

- [Color logo](ai-multi.svg) and [dark theme variant](ai-multi-dark.svg): scalable artwork matching the packaged 40 × 40 plugin icons.
- [Monochrome agent icon](ai-multi-monochrome.svg) and [dark theme variant](ai-multi-monochrome-dark.svg): 16 × 16 native dropdown assets.
- Profile silhouettes and separators are packaged under `src/main/resources/icons/`.

Chat profile choices combine the profile silhouette, separator and installed agent's own icon. Missing agent icons use the generic AI Multi mark. Preserve light/dark variants and native sizing.

The SVG paths are original project artwork. Design references: [Lucide Sparkles](https://lucide.dev/icons/sparkles) and [Lucide Users Round](https://lucide.dev/icons/users-round). See JetBrains' [plugin logo guide](https://plugins.jetbrains.com/docs/intellij/plugin-icon-file.html) and [icon requirements](https://plugins.jetbrains.com/docs/intellij/icons.html).
