# Quick-start screenshots

These are real native plugin/client UI captures with synthetic profiles, not generated mockups. Images were visually reviewed before publication.

- `profile-settings-personal-work.png`: the actual plugin General settings tab with synthetic Personal and Work profiles, Work selected and Personal marked as the project default. A local synthetic ACP agent named Codex is registered in the sandbox so agent availability is checked through the native client. No real account authorization is used.
- `chat-work-account.png`: the actual Air composer with AI Multi and Work selected, using the synthetic work@example.test identity and example model fixtures. Only the native composer component is rendered into the capture; primary IDE windows, project files and unrelated notifications are excluded.
- `switch-ai-profile.png`: the actual Switch AI Profile dialog, captured from the native UI with synthetic Codex Mock and Grok Mock labels. The additional-instructions field contains a font sample, not user content. No account, token, or project data is shown.
- `grok-permission-mode.png`: a layout rendering of the Air composer bar for the Grok permission chip. The labels match the plugin: AI Multi, Grok, grok-4.7, Medium, and Ask, with the menu Ask, Auto-review, and Always approve. The account is the synthetic `grok@example.test`. It is not a capture from a signed-in IDE.

All other local screenshots remain excluded. Do not publish screenshots containing real account email, account IDs, tokens, private project content or authorization data.
